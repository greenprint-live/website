# 🚀 Enhanced Data Simulation Demo

## Amazing New Features!

### 🎛️ **Configurable Simulation Modal**
- **Quick Presets**: Gentle, Normal, Aggressive, Chaotic
- **Custom Parameters**: Fine-tune every aspect of simulation
- **Real-time Preview**: See intensity levels as you configure

### ⚡ **Aggressive & Random Simulation**
- **High Volatility**: Values can swing dramatically (up to 90%)
- **Anomaly Generation**: Random unusual readings (up to 40% chance)
- **Spike Mode**: Extreme value spikes (up to 500% intensity)
- **Burst Updates**: Multiple rapid-fire updates in succession
- **Trend Disruption**: Break natural trends for chaos

### 🎯 **Simulation Presets**

#### 🌱 **Gentle Mode**
- 5-second intervals
- 15% volatility
- 70% trend persistence
- 5% anomaly chance
- Perfect for steady monitoring

#### 📊 **Normal Mode** 
- 3-second intervals
- 30% volatility
- 50% trend persistence
- 10% anomaly chance
- Balanced realistic simulation

#### 🔥 **Aggressive Mode**
- 1-second intervals
- 60% volatility
- 30% trend persistence
- 20% anomaly chance
- Burst mode enabled
- Spike mode enabled
- High-energy simulation

#### 🌪️ **Chaotic Mode**
- 500ms intervals (2x per second!)
- 90% volatility
- 10% trend persistence
- 40% anomaly chance
- 8 updates per burst
- 500% spike intensity
- Complete mayhem!

### 📈 **Real-time Statistics**
- **Total Updates**: Live counter of data points generated
- **Anomalies**: Count of unusual readings
- **Spikes**: Count of extreme values
- **Visual Indicators**: Pulsing "Simulating" badge
- **Color-coded Stats**: Orange for anomalies, red for spikes

### 🎨 **Enhanced Visual Feedback**
- **Pulse Animations**: Green flash when sensors update
- **Status Badges**: Live connection and simulation status
- **Intensity Indicators**: Color-coded simulation intensity
- **Real-time Counters**: Live stats in the header

## 🧪 **How to Test**

1. **Create Test Data**: `mix run test_data_api.exs`
2. **Open Hub Display**: Navigate to the hub URL
3. **Click "Simulate Data"**: Opens the configuration modal
4. **Try Different Presets**:
   - Start with "Gentle" to see basic simulation
   - Move to "Aggressive" for high-energy updates
   - Go "Chaotic" for complete mayhem!
5. **Watch the Magic**: 
   - See sensors update in real-time
   - Watch anomaly and spike counters
   - Enjoy the visual feedback
